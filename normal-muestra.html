Sesión 4 · normal estándar y t-Student · Sesión 5 · tamaño de muestra

Leer la tabla, estandarizar y decidir cuántos datos hacen falta

Practica con las tablas del curso: la normal estándar (cola izquierda) y la t-Student. Estandariza una variable normal de 2026 para hallar probabilidades y percentiles, y calcula el tamaño de muestra para una media y para una proporción. Cada intento trae casos nuevos, tienes 20 minutos y el cronómetro te avisa cuando falten 3.

Lo que vas a usar
Normal estándar Z ~ N(0, 1)La tabla da P(Z ≤ z), el área a la izquierda. «Mayor que» se obtiene con 1 − P(Z ≤ z); «entre» es una resta.
EstandarizarSi X ~ N(μ, σ²), entonces Z = (X − μ) / σ tiene distribución N(0, 1). Así cualquier normal se lee en la misma tabla.
t-Student t(r)Campana centrada en 0 con colas más pesadas; depende de los grados de libertad r. Su tabla también es de cola izquierda.
Tamaño de muestraPara una media: n = z²σ²/ε². Para una proporción: n = z²p(1 − p)/ε². Con N finita se corrige y siempre se redondea hacia arriba.
Normal estándar: P(a ≤ Z ≤ b) = P(Z ≤ b) − P(Z < a) P(Z ≥ a) = 1 − P(Z < a) P(Z ≥ −a) = P(Z ≤ a) Estandarizar: Z = (X − μ) / σ Percentil: busca el área en el cuerpo de la tabla; k = μ + z · σ Media: n₀ = z² · σ² / ε² con N finita: n = n₀ / (1 + n₀ / N) Proporción: n₀ = z² · p(1 − p) / ε² sin información previa: p = 0.5 z = z(1 − α/2): el área a la izquierda de z es 1 − α/2 (95 % → área 0.975 → z = 1.96). Redondea z a 2 decimales y escribe las probabilidades con 4 o 5 decimales; el lector acepta decimales o fracciones. El tamaño de muestra es un entero, siempre hacia arriba.
